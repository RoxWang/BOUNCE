# BOUNCE — 球有限，弹道看得见

一个网页游戏合集。打开就玩，不用下载、不用注册、断网也能玩。

👉 **直接玩：https://roxwang.github.io/BOUNCE/**

## 怎么用（一句话）

打开上面的链接 → 合集首页点一张游戏卡片 → 按住拖动瞄准 → 松手发射。手机、平板、电脑都一样。

## 里面有两个游戏

| 游戏 | 玩什么 | 核心规则 |
| --- | --- | --- |
| **弹珠模式** | 200 关解谜，用有限的球清空金色目标砖 | 虚线就是球**真实会走**的路线，能算多远就走多远；省下的球换成金币 |
| **无尽冲刺** | 躲开下落的方块刷分 | 撞到就结束，攒金币买永久强化，一次比一次跑得远 |

## 弹珠模式怎么玩

- **瞄准**：场上按住拖动，或 `←→` 调角度、`↑↓` 调力度、`空格` 发射（手机用屏幕箭头）。
- **谋划**：虚线只显示前几次反弹，后面靠你自己算。钢块能当跳板、炸弹一碰就炸、传送门会换位置、弹板把你弹开。
- **省球**：球用完还没清空目标 = 游戏结束。真正的难题不是「能不能过」，是「用几颗球过」。
- **强化**：过关攒金币买永久升级，阵亡不丢，越往后越好打。

## 装成独立 App（可选）

用 Chrome / Edge 打开游戏链接 → 地址栏点「安装」（手机是「添加到主屏幕」），桌面就多一个 BOUNCE 图标，没有浏览器边框，离线也能玩。
