# BOUNCE

一个打开浏览器就能玩的小游戏合集。

👉 **开始玩：https://roxwang.github.io/BOUNCE/**

## 游戏

**弹珠解谜** — 用有限的球清空场上所有金色目标砖。按住拖动瞄准，虚线就是球真实会走的路线；钢块能当跳板、炸弹一碰就炸、传送门会换位置、弹板把你弹开。球用完就结束，所以要算的是用几颗球过关。关卡全部开放，随时能停。

**无尽冲刺** — 躲开不断落下的方块，活得越久分越高。路上能捡护盾、缓速和金币，攒下的金币买永久强化，下一局跑得更远。

## 操作

按住往任意方向拖动瞄准、松手发射；也可以 `←→` 调角度、`↑↓` 调力度、`空格` 发射，手机上点屏幕方向键。进度自动存在浏览器里，关掉再打开接着玩。
