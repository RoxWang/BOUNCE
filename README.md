## 游戏

**弹珠解谜** — 用有限的球清空场上所有金色目标砖。按住往任意方向拖动瞄准，球会从边框沿这个方向打进来，虚线就是球真实会走的路线；钢块能当跳板、炸弹一碰就炸、传送门会换位置、弹板把你弹开。球用完就结束，所以要算的是用几颗球过关。关卡全部开放，随时能停。

**无尽冲刺** — 躲开不断落下的方块，活得越久分越高。路上能捡护盾、缓速和金币，攒下的金币买永久强化，下一局跑得更远。

**跳跃拾金** — 30 关平台跳跃，每关跑到金色旗子就过关。`←→` 或 `A D` 跑，`空格` 跳，短按小跳、按住大跳，不能二段跳。每段路都有两条：金色 `↑` 高台金币多但要连跳、后面还有怪；白色 `→` 走地面更稳、金币少，两条路在段末汇合。关卡布局固定不变，第二次玩能记住坑在哪；关卡全开不用解锁，通关给一到三星。碰尖刺、撞怪、掉下去各扣 1 条命，3 条命用完就结束。金币进同一个金库，买永久强化；手机用屏幕上的三个方向键。

**轨道狂奔** — 三条轨道一直往前跑的无尽模式，没有终点，越跑越快。`←→` 或 `A D` 换道，`↑` / `空格` 跳过橙色低栏，`↓` 从黄色横杆下滑钻过去，红色车厢只能提前换道。金币串铺在有障碍的道上，想拿满就得跳着、滑着穿过去，空道只留一枚；跳过、钻过、贴着车厢擦过去都攒连击，得分和每枚金币跟着涨，撞一次清零。障碍两三排一组，有连跳、跳接滑、之字换道和没有障碍的冲刺段，看准节奏再动。每排至少留一条空道，地面标线会提前亮出安全道。撞一次扣 1 条命，3 条命用完就结束。路上能捡三种 buff（限时磁石自动吸金币、限时双倍分、护盾挡一次伤害），金币去「强化」买永久加成：多一条命、开局带护盾、磁石范围、得分加成。桌面用方向键或在画面上拖动，Mac 触控板不用双指手势；手机用屏幕方向键。

## 怎么用（一句话）

打开上面的链接 → 在大厅点想玩的游戏 → 用键盘 / 鼠标 / 手指操作，画面上会写这个游戏怎么按 → 关掉再打开接着玩。手机、电脑、平板都一样。

## 四种方式，挑最适合你的

| 方式 | 适合谁 | 核心点（✓ 优点 / ✗ 注意） |
|---|---|---|
| **网页版**（上面的链接） | 所有人，首选 | ✓ 打开就玩、不用装、永远最新、全平台 ／ ✗ 首次要联网（之后浏览器会缓存，可离线） |
| 浏览器「安装为应用」 | 想有桌面图标、不占空间 | ✓ 和网页同一套，变成独立窗口 ／ ✗ 本质还是网页，首次要联网 |
| **Mac App**（仅 macOS） | Mac 用户，要桌面图标双击直开 / 断网 | ✓ 双击就开、App 里自带一份游戏、能离线 ／ ✗ 仅 macOS；首次打开会被 macOS 拦一下，点「仍要打开」即可 |
| **独立 HTML**（全平台） | Windows / Linux 想**断网**用、或想随身带一个文件 | ✓ 就一个文件、**断网也能玩**、跨平台 ／ ✗ 要手动下载、更新需重新下 |

⚠️ 四种里只有 **Mac App** 首次打开会被 macOS 弹窗拦一下（没上架 App Store），其余三种不会弹窗。

## 怎么弄（每一步）

> **去 Releases 后只下这两个，别的（Source code 那两个）是源码、普通人不用管：**
> - `BOUNCE-1.0.zip` = Mac App（Mac 用户下这个）
> - `BOUNCE-standalone.html` = 离线单文件游戏（Windows / Linux / 想断网的下这个）

1. **网页版**：直接打开最上面的链接，完事。
2. **浏览器「安装为应用」**：打开链接 → 浏览器右上角菜单（Chrome / Edge 点 `⋮`）→「安装此站点为应用 / Install」→ 桌面出现图标。
3. **Mac App**：① 点 [Releases](https://github.com/RoxWang/BOUNCE/releases) → ② 点 `BOUNCE-1.0.zip` 下载 → ③ 双击解压得到 `BOUNCE.app` → ④ 拖进「应用程序」文件夹（首次打开若被 macOS 拦，去「系统设置 → 隐私与安全性」点「仍要打开」）。
4. **独立 HTML（断网 / 随身版）**：去 [Releases](https://github.com/RoxWang/BOUNCE/releases) 下载 `BOUNCE-standalone.html` → 双击（用默认浏览器打开）就能玩，断网也行。
